Your request:

    %1$s

Expected request scheme:

    %2$s register PATH REGISTRY NAME_LEN [OPTIONS]
    %2$s register [PATH/]DEEP REGISTRY NAME_LEN [OPTIONS]
    %2$s register [PATH/][DEEP/]PATTERN REGISTRY NAME_LEN [OPTIONS]

    ... to register unique regular files that meet certain criteria located in
        a given processing directory and move duplicates into a trash directory.

        Unique files will be renamed with a unique filename component.

        Empty subdirectories will finally be removed (see CLEAN).

Parameters:

    PATH      - A path to be examined.
              - Default: the path of the current working directory (cwd)
    DEEP      - One of {**, .**, :**}
                **      : also list files contained in visible* subdirectories
                .**     : [not yet implemented:]
                          also list files contained in invisible* subdirectories
                :**     : also list files contained in any subdirectory
              - Default : don't list files contained in any subdirectory
    PATTERN   - A pattern for matching the simple filenames of the files to be listed.
                May contain usual wildcards {?, *} with their usual meanings.
                May be prefixed by {:} -> also list invisible* files that matches
                the rest of the PATTERN. By default only list visible* files,
                unless the pattern starts with dot (.) and thus explicitly matches
                invisible* files.
              - Default : * (match any visible* file)
    REGISTRY  - A path to the registry directory.
    NAME_LEN  - The maximum length of the substring of the original filename
                that will be retained to generate the new, unique filename.
    OPTIONS   - Consists of [n:N_PATTERN] [x:X_PATTERN]
    N_PATTERN - An extended pattern for (additionally) matching the simple
                filenames of the files to be listed.
                Consists of [METHOD:[OPTION:]]VALUE
                METHOD - One of {rx, wc} (case-insensitive)
                         rx : the VALUE is treated as a regular expression.
                         wc : the VALUE is treated as the full file name,
                              but allows the use of usual wildcards {?, *}.
                       - Default: wc (pattern with wildcards)
                OPTION - One of {cs, ci} (case-insensitive)
                         cs : the pattern will be applied case-sensitive.
                         ci : the pattern will be applied case-insensitive.
                       - Default: ci (case-insensitive)
                VALUE  - A pattern value to be applied to the METHOD along
                         with the simple filenames in question.
    X_PATTERN - An extended pattern for matching the simple filenames
                of files to be excluded from listing.
                Consists of [METHOD:[OPTION:]]VALUE  ... (see N_PATTERN)
