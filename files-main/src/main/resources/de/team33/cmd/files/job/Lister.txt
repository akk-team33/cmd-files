Your request:

    %1$s

Expected request scheme:

    %2$s list PATH [OPTIONS]
    %2$s list [PATH/]DEEP [OPTIONS]
    %2$s list [PATH/][DEEP/]PATTERN [OPTIONS]

    ... to list files that meet certain criteria within a specific directory.

        In the following, files whose simple name begins with a dot (.)
        are referred to as invisible* files; all others are referred to
        as visible* files.

Parameters:

    PATH      - A path to be examined.
              - Default: the path of the current working directory (cwd)
    DEEP      - One of {**, .**, :**}
                **      : also list files contained in visible* subdirectories
                .**     : [not yet implemented:]
                          also list files contained in invisible* subdirectories
                :**     : also list files contained in any subdirectory
              - Default : don't list files contained in any subdirectory
    PATTERN   - A pattern for matching the simple filenames of the files to be listed.
                May contain usual wildcards {?, *} with their usual meanings.
                May be prefixed by {:} -> also list invisible* files that matches
                the rest of the PATTERN. By default only list visible* files,
                unless the pattern starts with dot (.) and thus explicitly matches
                invisible* files.
              - Default : * (match any visible* file)
    OPTIONS   - Consists of [n:N_PATTERN] [x:X_PATTERN] [t:TYPES] [o:ORDER]
    N_PATTERN - An extended pattern for (additionally) matching the simple
                filenames of the files to be listed.
                Consists of [METHOD:[OPTION:]]VALUE
                METHOD - One of {rx, wc} (case-insensitive)
                         rx : the VALUE is treated as a regular expression.
                         wc : the VALUE is treated as the full file name,
                              but allows the use of usual wildcards {?, *}.
                       - Default: wc (pattern with wildcards)
                OPTION - One of {cs, ci} (case-insensitive)
                         cs : the pattern will be applied case-sensitive.
                         ci : the pattern will be applied case-insensitive.
                       - Default: ci (case-insensitive)
                VALUE  - A pattern value to be applied to the METHOD along
                         with the simple filenames in question.
    X_PATTERN - An extended pattern for matching the simple filenames
                of files to be excluded from listing.
                Consists of [METHOD:[OPTION:]]VALUE  ... (see N_PATTERN)
    TYPES     - A subset of {f, d, s, l, m, a} (case-insensitive)
                with the respective meanings:
                f : regular files
                d : directories
                s : special files
                l : symbolic links
                m : missing files (typically broken links)
                a : any file
              - Default: a (any file)
    ORDER     - An expression that specifies the sort order.
                Consists of CRITERION[:DIRECTION]
                CRITERION - One of {p, n, d, s} (case-insensitive)
                            p : order by full path
                            n : order by simple file name
                            d : order by date / time of last modification
                            s : order by file size
                DIRECTION - One of {a, d}
                            a : ascending order
                            d : descending order
                          - Default: a (ascending order)
              - Default : 'natural' (no specific) order

Examples:

[1] %2$s list 'path/to/images/**/*.jpg'

    ... to list visible* files whose names end with ".jpg" in the directory
        "path/to/images" and its visible* subdirectories. Output in default order.

[2] %2$s list 'path/to/images/:*' 'x:myFile.*'

    ... to list all files whose names do NOT start with "myFile."
        in the directory "path/to/images". Output in default order.

[3] %2$s list 'path/to/images/:**' 't:fl'

    ... to list visible* regular files and symbolic links in the directory
        "path/to/images" and all of its subdirectories. Output in default order.

[4] %2$s list * 'n:rx:.*\.(jpg|jpe|jpeg)' 'o:d:d'

    ... to list visible* files with any of the extensions {"jpg", "jpe", "jpeg"}
        in the current working directory. Output order by date / time
        of last modification, descending.

        (see [5])

[5] %2$s list . 'n:rx:.*\.(jpg|jpe|jpeg)' 'o:d:d'

    ... to list visible* files with any of the extensions {"jpg", "jpe", "jpeg"}
        in the current working directory. Output order by date / time
        of last modification, descending.

        (see [4])
